# Color Catcher

Color Catcher is a fun and vibrant desktop game built with Python and Tkinter. Test your reflexes by catching the right colored balls while avoiding the wrong ones!

## How to Play
1. The game will show a **Target Color** at the bottom of the screen.
2. Use the **Left/Right Arrow Keys** or **A/D Keys** to move your basket.
3. Catch the balls that match the target color to increase your score!
4. **Don't catch the wrong colors**, or you will lose a life!
5. **Press Spacebar** to pause/resume the game.

## Features
- Beautiful modern UI with vibrant colors.
- Dynamic difficulty: The game gets faster as you score more points.
- Local Leaderboard: Saves your top scores to compete with friends!

## Download & Play
You don't need Python installed to play! Just download the standalone executable file from the **Releases** page.

1. Go to the [Releases](../../releases/latest) section on the right side of this page.
2. Download the `ColorCatcher.exe` file.
3. Double-click the file to start playing instantly (Windows only).

## 🛠️ For Developers (Running from Source)

If you want to run the code yourself or modify the game:

1. Make sure you have [Python](https://www.python.org/) installed.
2. Clone this repository:
   ```bash
   git clone https://github.com/vamshika21/Color_Catcher.git
   ```
3. Run the game:
   ```bash
   python game.py
   ```
